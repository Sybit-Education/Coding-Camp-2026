## Schnellstart Webentwicklung (Vue.js 3) im Coding Camp

Willkommen zum Coding Camp!

Du arbeitest direkt im GitHub Codespace – alles ist bereit:  
**Node.js**, **npm** und alles Weitere sind schon installiert.

### 1. Projekt einrichten (einmal machen!)

Unten das Terminal öffnen und ausführen:

```bash
npm install
```

### 2. Entwicklungsserver starten

```bash
npm run dev
```

Im Terminal erscheint ein Link (meist `http://localhost:5173/`), den du über „Open in Browser” öffnen kannst.

---

### Dein Vue.js-Projekt erklärt

- **Startpunkt:** `src/App.vue`
- **Eigene Bausteine:** `src/components/`
- **Navigation:** `src/router/index.ts`
- **Globale Daten:** `src/stores`
  **Seiten:** `src/views`
- **Kannst du alles ändern & speichern → Die Seite aktualisiert sich automatisch**

---

### Die wichtigsten Befehle

| Befehl           | Was passiert?                          |
|------------------|----------------------------------------|
| `npm install`    | Einmal starten, installiert alles      |
| `npm run dev`    | Startet die App zum Ausprobieren       |
| `npm run build`  | Macht eine finale ("fertige") Version  |
| `npm run lint`   | Prüft, ob alles schön & ohne Fehler ist|

---

### Hilfe, wenn etwas klemmt!

- **Fehler in der Konsole?** Lies die Meldung – meist steht die Lösung direkt da!
- **Seite lädt nicht?** Prüfe, ob der Server läuft – sonst nochmal `npm run dev`.
- **Browser zeigt alte Version?** Seite neu laden:  
  `Strg+Shift+R` (Windows/Linux)  
  `Cmd+Shift+R` (Mac)
